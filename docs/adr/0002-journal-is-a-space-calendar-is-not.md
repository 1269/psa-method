# The Journal is a space; the Calendar is not

A **space** is defined by one property: it can mirror the Projects / Systems / Archives structure. A journal can — notebooks, folders, or sections named for the three stages, with entries filed or routed into them — so the Journal is the fourth standard space (the capture layer). A calendar cannot: events aren't projects, systems, or archives, and forcing the mirror onto a calendar produces nothing useful.

The Calendar is instead a **PSA-aware component**: it reads the spaces (active projects, armed tasks) and writes time blocks, so agents can schedule work inside your available hours. This keeps the teachable core honest — "four spaces that mirror the structure, one component that schedules it" — instead of diluting *space* to mean "any tool you use."
